# MVU Auto Doctor 2.1 未决项

以下事项明确不属于 2.0.0 RC，不得在发布阶段临时扩大范围：

1. 显式、可预览的分支合并与冲突解决协议。
2. 多玩家并发行动、主持人权限和跨客户端租约仲裁。
3. 跨聊天/跨世界的事实引用、知识迁移与撤销。
4. 可视化导演时间线、事务图和因果图。
5. 可安装、版本化的世界规则、槽位、资源别名和检定适配包。
6. 更丰富的 H2 折算策略与主持人自定义裁定模板。
7. 基于匿名、用户明确同意的真实容量数据继续优化大聊天迁移性能。
8. 发布包签名、可复现构建证明和多平台安装器集成。

2.0.0 继续禁止隐式分支合并、猜测旧机械字段、主模型作为唯一硬边界，以及未经
用户授权收集真实聊天或凭据。上述项目只有在独立规格、隐私评审和回放用例建立后才
能进入实现。

阶段8的 Actor Shard“提案汇合”不属于第1项的分支合并：它不合并聊天分支、事实
账本或事务，只在同一 settled 目标内把兼容的幕后候选交给宏观连续性模型复核。
