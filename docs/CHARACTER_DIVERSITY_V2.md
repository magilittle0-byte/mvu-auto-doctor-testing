# 人物多样化 V2.3：参考预设蒸馏与生成前骰票

本轮只读分析了用户提供的《糖糖公司 V3.2 正式版》和《小猫之神 4.0test》，没有修改原文件，也没有直接复制其中的角色类型表。

## 2026-08-10：从“给维度”改为“脚本先掷组合”

- 只告诉模型考虑多个维度仍会让它自己选择熟悉模板，因此医生现在在主回复生成前本地掷出三张未命名人物骰票。
- 每张票分别从十二个独立池选择价值、气质、个人生活目标、社交办法、权威态度、决策习惯、说话节奏、幽默方式、普通缺点、关系距离、日常纹理和压力—恢复路径；选择由脚本完成，模型不能自己挑票。
- 人物万花筒预设负责在原创NPC第一次落笔前使用骰票塑形；首次只显露最多三项。医生在正文生成后识别新人物，按首次出现顺序绑定同一张票，再将正文证据写成硬锚点、用不冲突骰轴补齐尚未显露的档案字段。
- 固定优先级是“数据库/角色卡/原著 > 已接受正文 > 缝合怪明确人物设定 > 已保存档案 > 骰票”。冲突时丢弃单个骰轴，不折中改写上层输入；没有新人物时不消费骰票，也不为用票强行加人。
- 糖糖公司的参考价值在于不同人格同时改变称呼、权力距离、耐心、幽默和工作动机，而不只是替换形容词。本项目据此扩展了独立轴和组合机制，但没有复制其中的具体人格角色。

## 吸收的机制

- 偏好不等于能力上限：训练、职责和生活经验可以形成与本能偏好相反的熟练做法。
- 人物会随压力进入不同应对模式，也有自己的恢复条件；压力状态不能覆盖长期人格。
- 关系距离因对象、处境和既往选择而变化，不用一个全局依恋标签解释所有关系。
- 人物有不围着玩家转的现实目标、手边小事、离场生活和有限认知，也会发生典型误读并在获得新证据后修正。
- 人设应通过普通动作、说话节奏、信息选择和有代价的决定显影，不靠旁白反复宣布。
- 首次出场保持低带宽，群像先覆盖全部持续人物；删掉姓名、职业和类型标签后仍应能从选择方式认出角色。

## 明确不移植的部分

- 不生成或保存 MBTI、九型、Tritype、依恋型、星座、病娇、地雷、白切黑或 S/M 等类型标签。
- 不把“核心动机恒定”写成不可变化的单因人格，也不强制每个人拥有创伤、反差、秘密或极端欲望。
- 不要求全员情绪平淡、统一非理性、统一温柔、统一道歉或最终互相理解。
- 不用类型组合表替代行为证据；角色卡明确提供类型时，也只视为弱参考。

## 落地位置

- Actor Ledger v4：保存信息取样与典型误读、关系距离模式、自我形象与行为缝隙、习得的逆倾向能力、受压反应与恢复路径。
- 人物分片：使用上述证据推演离场人物行动；没有证据时不把猜测升级成确认事实。独立人物档案填表可用已绑定骰票补齐创作空白，但来源保持可重写假设。
- 人物关系二审：类型标签捷径和群体整齐反应会进入语义复核；有证据的黑暗内容仍可放行。
- 人物万花筒 V2：限制首次出场的信息带宽，增加群像覆盖和三层换名碰撞检查。

## 正文渲染边界

人物万花筒预设继续支持 `<story_body>` 的沉浸阅读排版，以及剧情中真实手机聊天的左右气泡。它能美化正文和消息载体，但不会凭提示词自动生成截图中的整页摄影背景；那类效果仍取决于酒馆主题、CSS 或专门的前端渲染脚本。

V2.3 的骰票链当前只完成本地逻辑与无头浏览器回归；下面的 Gemini 结果是 V2 的历史验证，不能作为 V2.3 的真实模型通过声明。

## 目标模型验证

2026-08-03 使用与用户跑团日志一致的 GemAI `gemini-3.1-pro-preview`，在四个纯合成场景中比较完整 rc.7 V1 合同与 rc.8 V2 合同：V2 为3胜0负1平。V2 在普通首次出场、类型标签诱导与逆倾向应压场景胜出，多人群像持平；六项均分全部提高，双方均未触发类型捷径、换名互换、首次过载、群体整齐、强行温情或无据加黑。

医生本体另完成3次同模型合成链路，人物分片、人物世界结算、势力轨和环境轨均成功。首次探针发现 Gemini 会给人物分片 JSON 加完整代码围栏，因此本地只新增“剥一层完整 JSON 围栏”的结构修复；说明文字、非法 JSON、额外字段、证据越界和写入越权仍然拒绝。详细数值见 `qc-reports/v2.0.0-rc.8-character-gemini.json`。
